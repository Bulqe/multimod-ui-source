MultiMod UI source download

Integration author: Bulqe. Original project credits and AGPL-3.0 license are
preserved inside multimod-ui-source-20261024.zip. LICENSE is also supplied separately.

This is UI-only source: 145 editable UI files, four upstream generators and build
instructions/notices. It is not the private server project or a playable map.
No server binaries, credentials, player records or private settings are included.

Verify the ZIP against SHA256SUMS.txt. Extract it and read README.md for the
Windows CS2 Workshop Tools build instructions. Do not treat hashes as signatures.
